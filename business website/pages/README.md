
# KJB Popcorn Website

## Project Overview

KJB Popcorn is a small-business website developed to demonstrate the
fundamental concepts of HTML.

The website introduces KJB Popcorn, displays its products and prices,
provides business information, publishes popcorn-related articles,
and allows customers to complete an event order enquiry form.

**Business Name:** KJB Popcorn

**Tagline:** One taste. You'll want more.

**Location:** Opposite FUTA Southgate, Akure, Ondo State, Nigeria.

## Project Objectives

The objectives of this project are to:

- Demonstrate the use of semantic HTML.
- Create a functional multi-page website structure.
- Implement accessible HTML navigation.
- Display information using HTML tables and lists.
- Create forms with different input types.
- Embed images and demonstrate multimedia elements.
- Apply appropriate HTML document structure and metadata.
- Practise relative file linking.

## HTML Concepts Demonstrated

This project demonstrates:

1. HTML document structure.
2. Headings and paragraphs.
3. Semantic elements such as header, nav, main, section,
   article, aside and footer.
4. Hyperlinks and relative paths.
5. Images, figures and captions.
6. Ordered and unordered lists.
7. HTML tables.
8. Forms and form controls.
9. Accessible labels and alternative text.
10. Audio and video elements.
11. Metadata and document titles.
12. HTML validation concepts.

## Technologies Used

- HTML5
- Visual Studio Code
- Web browser for testing

No CSS frameworks, JavaScript frameworks, Bootstrap or Tailwind CSS
were used in this HTML-only project.

## How to Run the Website

1. Download or copy the project folder.
2. Open the website folder in Visual Studio Code.
3. Locate index.html.
4. Open index.html in a web browser.
5. Use the navigation links to visit the other pages.

## Testing

The website should be tested for:

- Correct navigation between all pages.
- Working relative links.
- Proper heading hierarchy.
- Correct image file paths.
- Meaningful image alternative text.
- Form labels and input types.
- Required field validation.
- Correct table structure.
- Proper HTML document structure.

## Project Limitations

This project is an HTML-only demonstration.

The forms are not connected to a backend server and therefore do not
send customer enquiries or event orders to KJB Popcorn.

The website does not currently include a database, payment system,
customer account system or automated order processing.

## Conclusion

The KJB Popcorn website demonstrates how HTML can be used to build
the structure and content of a multi-page small-business website.

It provides a foundation for future improvements involving CSS,
JavaScript, backend development and database integration.
